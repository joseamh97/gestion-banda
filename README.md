# Gestión Banda

Aplicación web para la gestión de bandas de música.

## Tecnologías
- Vue 3
- Tailwind CSS
- Flask
- SQLAlchemy
- JWT

## Funcionalidades
- Gestión de usuarios
- Gestión de eventos
- Control de asistencias
- Gestión de partituras
- Inventario
- Dashboard estadístico
- Exportación Excel
- Responsive design
